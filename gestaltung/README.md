# Gestaltung

Hier wachsen Hintergründe und konkrete Vorschläge zu einzelnen Thesen: von der Problembeschreibung über Quellen bis zu Formulierungsentwürfen für Gesetze, Standards oder Prüflisten.

Anders als [THESEN.md](../THESEN.md) wird dieser Ordner nicht mitgezeichnet. Er darf frei wachsen und sich verändern.

## Aufbau

Jede These bekommt bei Bedarf einen eigenen Ordner nach dem Muster `NN-stichwort`:

```
gestaltung/
├── 03-treuepflicht/
│   ├── hintergrund.md   Problem, Quellen, Stand der Debatte
│   └── vorschlag.md     Konkreter Vorschlag, z. B. Gesetzesformulierung
└── 10-ausweispflicht/
    └── …
```

Vorlagen für beide Dateien liegen in [`_vorlage/`](_vorlage/).
